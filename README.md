# 🚀 Sandun Dimantha | Full Stack Developer Portfolio

Welcome to the official repository of my modern, interactive Developer Portfolio built with Next.js 15, Framer Motion, and Tailwind CSS.

---

## ✨ Features

- **🛡️ Premium Glassmorphic Design**: Clean and interactive layout with dark/light mode toggle.
- **✨ Animated Running Light Borders**: Glowing, animated card elements using CSS conic-gradients.
- **🔄 Real-time GitHub Integration**: Live stats, contribution graphs, and auto-synced repository status.
- **💻 Interactive Command Palette**: Search through page sections, projects, and contact targets using `Ctrl + K`.
- **🚀 Animated Previews & Media**: High-quality PNG rendering extracts for my professional qualifications/certificates.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router & Turbopack)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) & Native CSS Custom Properties
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & CSS keyframes
- **Icons**: React Icons (Fa, Si)
- **Deployment**: Live hosted repository syncs

---

## 📦 Project Structure

```bash
portfolio/

├── data/                 # Custom local databases, project details, and certifications

```

## 🚀 Getting Started

Follow these steps to run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/sandundimantha/my-portfolio.git
   ```
2. Navigate into the directory:
   ```bash
   cd portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the live site.
